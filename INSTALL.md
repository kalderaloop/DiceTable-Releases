# Installation und Direkt-Update

1. `DiceTable-0.1.0.apk` aus dem Release `v0.1.0` laden und den Android-Systemdialog bestätigen.
2. In DiceTable **Über / Update** öffnen und nach dem Update suchen.
3. DiceTable prüft Größe, SHA-256, Paket-ID und Signierzertifikat, bevor der Android-Systeminstaller geöffnet wird.
4. Android kann einmalig die Freigabe **Unbekannte Apps installieren** für DiceTable verlangen. Eine stille Installation findet nicht statt.

Prüfsummen liegen bei jedem Release als `.sha256`-Datei.
